## Data mode

Data mode renders a single ARIA grid from data instead of slotted rows.
It turns on when `columns` is non-empty, or when the table has at least one `sgds-data-table-column` child.
The `columns` property takes precedence over column children.
Slotted mode (`sgds-data-table-row`, `sgds-data-table-head` and `sgds-data-table-cell`) keeps working without changes.

### Columns property

Pass column definitions through `columns` and row objects through `rows`.
Each row needs a stable identity in the field named by `rowKey` (default `"id"`).
Set `label` to give the grid an accessible name when no visible heading labels it.

<Canvas of={DataTableStories.DataModeColumns}>
  <Story of={DataTableStories.DataModeColumns} />
</Canvas>

```js
const table = document.querySelector("sgds-data-table");
table.columns = [
  { key: "name", header: "Name", sortable: true },
  { key: "age", header: "Age", sortable: true, align: "right" }
];
table.rows = [
  { id: 1, name: "Amy Tan", age: 28 },
  { id: 2, name: "Ben Lim", age: 35 }
];
```

### Server mode

Use `mode="server"` when your API returns one page at a time. Pass only the current page in `rows` and the total in `dataLength`.
Set `serverSort` and `serverFilter` to turn off local sorting and filtering.
The table still updates its own `sort`, `globalFilter`, `columnFilters` and `currentPage` and emits `sgds-sort`, `sgds-filter` and `sgds-page-change`.
Listen to these events, request the matching page, then replace `rows` and `dataLength`. Set `loading` while the request is in progress.

<Canvas of={DataTableStories.DataModeServer}>
  <Story of={DataTableStories.DataModeServer} />
</Canvas>

```js
const table = document.querySelector("sgds-data-table");
const reload = async () => {
  table.loading = true;
  const { rows, total } = await fetchStaff({
    sort: table.sort,
    globalFilter: table.globalFilter,
    columnFilters: table.columnFilters,
    page: table.currentPage,
    pageSize: table.itemsPerPage
  });
  table.rows = rows;
  table.dataLength = total;
  table.loading = false;
};
table.addEventListener("sgds-sort", reload);
table.addEventListener("sgds-filter", reload);
table.addEventListener("sgds-page-change", reload);
```

### Keyboard navigation

The grid is a single tab stop and follows the WAI-ARIA APG data grid pattern.
Exactly one cell, or the filter input inside it, has `tabindex="0"`. The table remembers that position, and after a sort or page change it moves focus to the nearest valid cell.

<Canvas of={DataTableStories.DataModeKeyboard}>
  <Story of={DataTableStories.DataModeKeyboard} />
</Canvas>

| Key                                                  | Action                                                                                   |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Tab                                                  | Moves focus into the grid, to the last focused cell. Pressing Tab again leaves the grid. |
| Arrow right, Arrow left                              | Moves focus one cell right or left.                                                      |
| Arrow down, Arrow up                                 | Moves focus one row down or up, including between the header, filter and body rows.      |
| Home, End                                            | Moves focus to the first or last cell of the current row.                                |
| Ctrl + Home, Ctrl + End                              | Moves focus to the first or last cell of the grid.                                       |
| Page up, Page down                                   | Goes to the previous or next page in client pagination.                                  |
| Enter, Space on a sortable header                    | Sorts by the column.                                                                     |
| Shift + Enter, Shift + Space on a sortable header    | Adds the column to the sort when `multiSort` is set.                                     |
| Enter, Space on a checkbox cell                      | Toggles the row selection. On the header checkbox cell, toggles select-all for the page. |
| Arrow left, Arrow right, Home, End in a filter input | Edits the filter text.                                                                   |
| Arrow up, Arrow down in a filter input               | Leaves the input and moves to the row above or below.                                    |

### Accessibility

- The grid is a native `table` with `role="grid"`, `aria-label` from `label`, `aria-rowcount` and `aria-colcount`. Each row has a 1-based `aria-rowindex` that counts header rows and, in client mode, the page offset.
- Header cells are `th scope="col"` and body cells are `td role="gridcell"`.
- Only the primary sorted column has `aria-sort`. Other sorted columns include visually hidden text such as "sorted descending, priority 2".
- Each filter input has an accessible name of the form "Filter Name".
- With `multiSelect`, the grid has `aria-multiselectable="true"` and selected rows have `aria-selected="true"`. Checkboxes are labelled "Select all rows" and "Select row 1".
- A visually hidden `role="status"` live region announces the number of results after a filter, sort or page change.
- While `loading`, the grid has `aria-busy="true"`.
- Set `label` when no visible heading names the table.

### Properties

| Property            | Attribute           | Type                                                 | Default         | Description                                                                  |
| ------------------- | ------------------- | ---------------------------------------------------- | --------------- | ---------------------------------------------------------------------------- |
| `columns`           | -                   | `SgdsDataTableColumnDefinition[]`                    | `[]`            | Column definitions. Takes precedence over `sgds-data-table-column` children. |

| `columnFilters`     | -                   | `Record<string, string>`                             | `{}`            | Per-column filter text keyed by column `key`.                                |
| `showGlobalFilter`  | `showGlobalFilter`  | `boolean`                                            | `false`         | Renders a search input above the grid.                                       |
| `serverFilter`      | `serverFilter`      | `boolean`                                            | `false`         | Turns off local filtering.                                                   |
| `serverSort`        | `serverSort`        | `boolean`                                            | `false`         | Turns off local sorting.                                                     |
| `mode`              | `mode`              | `"client" \| "server"`                               | `"client"`      | `server` turns off local pagination.                                         |
| `multiSelect`       | `multiSelect`       | `boolean`                                            | `false`         | Adds a checkbox column.                                                      |
| `selectedKeys`      | -                   | `(string \| number)[]`                               | `[]`            | Keys of the selected rows.                                                   |
| `density`           | `density`           | `"comfortable" \| "dense"`                           | `"comfortable"` | Row height and cell padding. Reflected.                                      |
| `stickyHeader`      | `stickyHeader`      | `boolean`                                            | `false`         | Keeps the header visible while the body scrolls. Reflected.                  |

| `loading`           | `loading`           | `boolean`                                            | `false`         | Shows skeleton rows and sets `aria-busy`.                                    |

#### Column definition

| Field        | Type                                                           | Description                                                          |
| ------------ | -------------------------------------------------------------- | -------------------------------------------------------------------- |
| `key`        | `string`                                                       | Field on each row, and the column identity in sort and filter state. |
| `header`     | `string`                                                       | Visible header label.                                                |
| `sortable`   | `boolean`                                                      | Enables sorting on the header.                                       |
| `filterable` | `boolean`                                                      | Adds a filter input for the column.                                  |

| Event                   | Detail                                                                                             | When                                                                                        |
| ----------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `sgds-sort`             | `{ key: string, direction: "ascending" \| "descending" \| "none", sort: SgdsDataTableSortSpec[] }` | Every sort change in data mode. In slotted mode, only with `serverSort` and without `sort`. |

### React

The React wrappers map the events to `onSgdsSort`, `onSgdsFilter`, `onSgdsPageChange` and `onSgdsSelectionChange`.
Pass `columns`, `rows`, `sort` and `selectedKeys` as props.
Prefer the `columns` prop in React. React reserves the `key` prop, so it does not reach `SgdsDataTableColumn`.

```jsx
import { useState } from "react";
import { SgdsDataTable } from "@govtechsg/sgds-web-component/react";

const columns = [
  { key: "name", header: "Name", sortable: true },
  { key: "department", header: "Department", sortable: true, filterable: true },
  { key: "age", header: "Age", sortable: true, align: "right" }
];

const rows = [
  { id: 1, name: "Amy Tan", department: "Finance", age: 28 },
  { id: 2, name: "Ben Lim", department: "Engineering", age: 35 }
];

export function StaffTable() {
  const [selectedKeys, setSelectedKeys] = useState([]);
  return (
    <SgdsDataTable
      label="Staff directory"
      columns={columns}
      rows={rows}
      multiSelect
      multiSort
      selectedKeys={selectedKeys}
      onSgdsSort={e => console.log(e.detail.sort)}
      onSgdsFilter={e => console.log(e.detail.filteredCount)}
      onSgdsPageChange={e => console.log(e.detail.currentPage)}
      onSgdsSelectionChange={e => setSelectedKeys(e.detail.selectedKeys)}
    />
  );
}
```
